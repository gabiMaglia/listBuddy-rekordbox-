# T-086 (b) — Auditoría de seguridad pre-release 1.0.0

Fecha: 2026-10-15 · Auditor: nerv-security · Alcance: solo lectura sobre `main` (commit b303da4).
PoCs y scripts en `/private/tmp/claude-501/-Users-gabrielsk-Desktop-REKORDBOX-EXTRACTOR/0eba9834-e91d-46a2-813c-c2d961ec1706/scratchpad/audit-seguridad/` (`poc_xml.py`, `poc_sanitize.py`, `poc_worker.py`, `poc_bigxml.py`, `poc_write_xml.py`). Todos corren contenidos en un tmp propio; ninguno toca archivos del sistema ni del repo.

## Resumen ejecutivo

1. No hay hallazgos **Críticos**. Nada bloquea 1.0.0 por sí solo, pero hay dos cosas que conviene resolver **antes** de publicar: el FFmpeg 7.1.3 que viaja dentro de PySide6 6.11.1 tiene CVEs de escritura fuera de límites con archivos de audio/MP4 malformados (SEC-01), y el `entitlements.plist` apaga la validación de librerías del Hardened Runtime sin evidencia de que haga falta (SEC-05).
2. El parser XML está bien: XXE, billion laughs, quadratic blowup y `&#0;` se rechazan (PoC verificado con expat 2.8.4). El único problema real del XML es memoria: `ET.parse` usa ~6,4× el tamaño del archivo (300 MB → 2 GB RSS; 2 GB → ~13 GB) (SEC-09).
3. La exportación escapa de la carpeta elegida con una playlist llamada `..` (copia al padre y pisa un `_no_exportados.txt` ajeno) y sigue symlinks tanto en origen como en destino (SEC-02/03/04). Son defectos de `sanitize()` y de `dest.exists()`, fáciles de arreglar.
4. Cadena de suministro y distribución: `requirements.txt` pineado pero sin `--hash`, `build_windows.ps1` instala PyInstaller sin pin, no hay releases publicados ni plan de checksums/firma para Windows (SEC-06/07). Python 3.14.7 trae expat 2.8.4; 3.14.8 ya trae 2.8.5 (SEC-08).
5. Privacidad: la app no manda nada salvo el chequeo de versión a GitHub (sin opt-out, URL del JSON abierta sin validar) y guarda rutas personales en logs/settings. Todo documentado en DISCLAIMER §8; faltan detalles menores (SEC-10/11/12).

## Modelo de amenazas (breve)

**Activos.** La librería del DJ (`collection.nml` de Traktor es *escrita* por la app; el XML de Rekordbox solo se lee), los archivos de música, la carpeta de destino del export y su contenido previo, `rekordbox_fixes.json`/`settings.ini`, el `.app`/`.exe` instalado, la reputación del autor (firma Developer ID).

**Actores.** (A1) un XML/NML malicioso o manipulado (por ejemplo, un «pack» de playlists compartido por otro DJ, o un archivo pasado por un disco USB ajeno); (A2) un archivo de audio malicioso al que apunte la librería; (A3) otro usuario/proceso local con permisos de escritura en la carpeta de destino o en el bundle (disco compartido, Mac multiusuario); (A4) un atacante en la red (MITM del chequeo de updates / del repo); (A5) la cadena de suministro (PyPI, GitHub, el Python de Homebrew del build).

**Superficies.** `xml.etree` sobre XML/NML de gigabytes; `shutil.copy2` con nombres derivados del XML; `os.walk` + escritura de `rekordbox_fixes.json` y del NML; QMediaPlayer/QAudioDecoder → FFmpeg 7.1.3 sobre archivos arbitrarios; `urllib` → api.github.com; el bundle PyInstaller firmado con `--deep` y entitlements relajados; los scripts de build.

Fuera de alcance / sin red: la app no escucha puertos, no usa `QNetworkAccessManager`, no evalúa código, no usa `shell=True` (verificado por grep sobre todo el código de producción).

## Verificado y OK

- **XXE / entidades externas** (`rekordbox_xml.open_library`, `traktor_db.open_collection`): expat rechaza `&xxe;` → `file:///…` con «reference to external entity in attribute»; una DTD externa `SYSTEM` no se descarga (0,00 s, `len(tree)=0`). ElementTree no define `ExternalEntityRefHandler`, y los docs de Python dicen que «by default, Expat does not access local files or create network connections». PoC `poc_xml.py`. Fuente: [docs.python.org/3/library/xml.html](https://docs.python.org/3/library/xml.html).
- **Billion laughs (10^9) y quadratic blowup (50 KB × 20k)**: rechazados por expat 2.8.4 con «limit on input amplification factor (from DTD and entities) breached», 4 MB / 17 MB de pico. Python documenta como vulnerables solo los expat < 2.7.2.
- **`&#0;` (NUL)**: expat lo rechaza («reference to invalid character number»), así que el caso `ValueError: embedded null byte` en `mkdir`/`copy2` no es alcanzable desde un XML.
- **Sin ejecución de comandos**: no hay `shell=True`, `os.system`, `eval`, `QProcess`; los dos `subprocess.run` (`diskutil info -plist /`, `pgrep -ix <patrón fijo>`, `tasklist /FI …`) usan listas fijas y `timeout=5`.
- **Red**: único cliente es `update_checker.py` (urllib + `ssl.create_default_context(cafile=certifi.where())`, `check_hostname=True`, timeout 4 s, sin fallback a «no verificar»). Sin telemetría, sin `QNetworkAccessManager` (CVE-2026-76151 de Qt 6.11.1 no aplica), sin Qt Quick (CVE-2026-79616 no aplica). QtSvg solo carga íconos propios (CVE-2026-6210 corregido en 6.11.1 igual).
- **`write_playlists_xml`**: rechaza destino == origen, destino symlink al origen y `sub/../origen` (`_same_file` con `resolve()` + `samefile`); escribe a `.tmp` + `os.replace`; permisos 0644. Test existente `test_refuses_symlink_to_the_source`.
- **Escrituras atómicas**: `FixStore.save`, `write_atomic` (NML) y `restore_backup` hacen tmp en la misma carpeta + `flush` + `fsync` + `os.replace`, y borran el tmp si falla.
- **Escritura del NML de Traktor**: backup previo con chequeo de espacio, retención 10, chequeo de «Traktor abierto» al inicio **y** justo antes de escribir, confirmación en UI, mensaje sin excepción cruda. `master.db` de Rekordbox: no se abre ni se escribe (grep de `pyrekordbox|sqlcipher|sqlalchemy` vacío; el spec los excluye).
- **Panel de log de la UI**: `QPlainTextEdit` (texto plano): nombres de pista/playlist con HTML no se interpretan.
- **Carpeta de datos**: `~/Library/Application Support/listBuddy` 0755 / `%APPDATA%\listBuddy`; `settings.ini` y `rekordbox_fixes.json` 0644; nada world-writable.
- **Relocate**: la búsqueda queda dentro de `search_root` (no sigue symlinks de carpeta), ignora `listBuddy_backups`, es cancelable; en un disco de red cada `exists()` puede tardar pero se chequea `should_stop` antes de cada uno (T-020).
- **PyInstaller**: `onedir` (no `onefile`: los CVE-2023-49797/2025-59042 y la validación nueva de `onefile` no aplican), `upx=False` en ambas plataformas (ADR-003, menos falsos positivos de AV), `excludes` de PyQt6/pyrekordbox, `strip=False`. `release_mac.sh` usa venv limpio, `--timestamp`, `--options runtime`, notariza con `--wait`, hace `stapler staple` del `.dmg` y `spctl --assess`.
- **Dependencias**: GitHub Advisory DB (consultado 2026-10-15 vía `gh api /advisories?ecosystem=pip`): 0 avisos para `pyside6`/`shiboken6`; los de `numpy` (≤ 2021), `certifi` (≤ 2024.7) y `pyinstaller` (≤ 6.0/6.10) son anteriores a las versiones pineadas. `certifi 2026.7.22` es la última en PyPI.
