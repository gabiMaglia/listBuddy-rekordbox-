Módulos

LB-01 EXPORT
Copia con prefijo numéricoBit a bit, sin re-encode. Nombre limpio de caracteres inválidos. Progreso y registro por lote. Verificación de integridad al final.
LB-02 PREVIEW
Vista previa y reproducciónLo que va a salir, playlist por playlist, antes de copiar. Reproductor con forma de onda y búsqueda. 800 playlists sin trabar la interfaz.
LB-03 RELOCATE
Reparación de enlacesArchivos movidos de disco: búsqueda por nombre, propuesta de ruta nueva. rekordbox: las reparaciones se guardan aparte y se puede generar un XML importable. Traktor: escribe el NML con copia de seguridad previa.
LB-04 INTEGRITY
Integridad del softwaremacOS: firmado con Developer ID y notarizado por Apple. Windows: sin firma, hash SHA‑256 publicado. Dependencias fijadas con hashes. Código fuente de cada versión junto a la descarga.
LB-05 PRIVACY
Sin redNo hay cuenta, servidor ni telemetría. La única conexión es el chequeo de versión nueva al iniciar, desactivable en Configuración → Privacidad.

06

FAQ

¿Hay que cerrar rekordbox? +

No. Se lee el XML exportado. Para escribir el NML de Traktor (reparación de enlaces) sí conviene cerrarlo.

¿Modifica la base de datos? +

Nunca abre ni escribe master.db. Las reparaciones de rekordbox van a un archivo propio; se puede generar un XML nuevo para importar.

¿Convierte o normaliza el audio? +

No. Copia el archivo original byte a byte; solo cambia el nombre del archivo de destino.

¿Qué cambia en la 1.1? +

Listas propias y exportación cruzada, con licencia de pago. La 1.0 queda disponible bajo GPL‑3.0, sin soporte.
