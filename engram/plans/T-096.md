# T-096 — Cadena de suministro y release

Aprobado por el PO: 2026-10-15 (corte T-086, `engram/audit/T-086_consolidado.md`). Cierra TEC-12, TEC-13, SEC-06, SEC-07, SEC-08, APP-17, LEG-07 (parte), D-27.

## QUÉ

1. TEC-12: el bundle no lleva QtPdf, QtQuick, QtQml (+QmlMeta/QmlModels/QmlWorkerScript), QtVirtualKeyboard (+Qml) ni los plugins `libqpdf` y `libqtvirtualkeyboardplugin`. Baja >= 15 MB. `check_bundle.sh` falla si reaparecen. Se quitan de THIRD_PARTY_NOTICES las filas de Qt Virtual Keyboard (GPL-3.0) y Qt PDF.
2. SEC-07: `requirements.txt` y `requirements-dev.txt` con hashes (generados con pip-compile desde `requirements.in` / `requirements-dev.in`); PyInstaller 6.20.0 pineado en `build_windows.ps1` y `release_mac.sh`.
3. SEC-08 / APP-17: `release_mac.sh` exige Python >= 3.14.8 (expat 2.8.5), acepta `PYTHON=`, avisa cómo instalarlo y aborta salvo `ALLOW_OLD_PYTHON=1`.
4. SEC-06 / D-27: `release_mac.sh` genera `.dmg.sha256` y `listbuddy-<v>-src.tar.gz` (+ `.sha256`); README explica cómo verificar.
5. TEC-13: `--dry-run` solo valida prerrequisitos e imprime el plan (sin build); `--skip-build` reusa `dist/`.

Fuera de alcance: firma Authenticode, mirror del repo, tarballs de Qt/FFmpeg, hashes de PyInstaller y sus dependencias por plataforma.

## CÓMO

- Spec: `excludes` con los módulos PySide6 + filtro final de `a.binaries`/`a.datas` por nombre (frameworks, `.so`/`.dylib`/`.dll`, plugins y QML) porque los hooks de PySide6 pueden arrastrarlos igual.
- `check_bundle.sh`: agrega patrones QtPdf/QtQuick/QtQml/QtVirtualKeyboard/qpdf al `find` prohibido.
- Hashes: pip-compile en venv del scratchpad; se verifica con `pip install --require-hashes` en venv limpio. El install de PyInstaller va en un `pip install` aparte (con `--require-hashes` activo no se mezclan requisitos sin hash).
- `release_mac.sh`: bloque `PYTHON`/versión antes de crear el venv; `--dry-run` imprime plan y sale tras validar (xmllint, Python, estado de `dist/`); `--skip-build` exige `dist/List Buddy.app`.

- requirements: toda línea de paquete tiene `--hash=sha256:`; `.in` existen; PyInstaller pineado en ambos scripts.
- release_mac.sh: 3.14.8, `PYTHON=`, `ALLOW_OLD_PYTHON`, sha256, `git archive`, `--skip-build`; `--dry-run` ejecutado de verdad no crea `build/` ni toca `dist/`.
- `git archive`: el tarball contiene LICENSE y THIRD_PARTY_NOTICES y no `.venv*`/`engram/` (export-ignore en `.gitattributes`).
