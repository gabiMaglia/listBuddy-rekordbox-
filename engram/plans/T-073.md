## Decisiones técnicas (T)

- **T1 — Identidad de una pista del alcance = su `raw_path` de la vista previa, comparado como string exacto.** Es el mismo valor que ya viaja en `TrackRow.raw_path`: en Traktor `str(_location_to_path(volume, dir, file))` (shim `TraktorTrack.FolderPath`) y en Rekordbox el `DjmdContent.FolderPath` crudo. Cada detector compara contra ese mismo cálculo (`str(file_path)` / `raw`), sin normalizar de nuevo: así no hay divergencia posible entre «lo que el usuario ve roto» y «lo que el motor intenta reparar». Descartado: `content_id`/`original_key` (la vista previa no los carga; agregarlos cambia `TrackRow`/caché de T-064).
- **T2 — `scope=None` ≠ `RelocateScope` vacío.** `None` = global (igual que hoy). Un alcance con `paths` vacío repara **nada** (0 rotos, `finished_ok(0,0,0,"ok")`), nunca se degrada a global (guardia contra «borré todo y repara toda la librería»).
- **T3 — El filtro va en la detección, antes del `.exists()`.** Ventaja: una corrida por carpeta no hace I/O sobre las miles de pistas fuera del alcance (en discos de red/USB cada `.exists()` puede tardar). `should_stop`/`on_progress` se conservan; el total reportado de progreso sigue siendo el de entradas recorridas.
- **T4 — Pista en dos playlists.** Es la misma entrada de COLLECTION / el mismo `DjmdContent`; al repararla desde una queda reparada para ambas. No hay código especial: se **declara** en el diálogo de confirmación (criterio 5) con una línea fija, sin consultar qué otras playlists la contienen (esa consulta exigiría cargar todas las playlists).
- **T5 — Corridas con alcance no leen el tilde del menú.** `_start_relocate(scope=…, auto_resolve=False|True)` toma `auto_resolve` del argumento (default `False` con alcance). El «Auto-resolver» de carpeta pasa `True` y **siempre** confirma con el diálogo de alcance. El tilde global del menú no se lee ni se modifica (criterio 6).
- **T6 — Sin decisión nueva para el PO.** Ninguna de T1–T5 cambia lo ya decidido en D1; se declaran al Orquestador por si veta alguna.

def _nml(tmp_path: Path, names: list[str]) -> Path:
    """NML sintético: una ENTRY rota por nombre + PLAYLISTS con una playlist que las lista todas."""
    entries = "".join(
        f'<ENTRY TITLE="{n}" ARTIST="A"><LOCATION VOLUME="Z:" DIR="/:nope/:" FILE="{n}.mp3"/></ENTRY>'
        for n in names
    )
    prims = "".join(f'<ENTRY><PRIMARYKEY TYPE="TRACK" KEY="Z:/:nope/:{n}.mp3"/></ENTRY>' for n in names)
    xml = (
        '<?xml version="1.0" encoding="UTF-8"?><NML VERSION="19">'
        f'<COLLECTION ENTRIES="{len(names)}">{entries}</COLLECTION>'
        f'<PLAYLISTS><NODE TYPE="FOLDER" NAME="$ROOT"><SUBNODES COUNT="1">'
        f'<NODE TYPE="PLAYLIST" NAME="all"><PLAYLIST ENTRIES="{len(names)}" TYPE="LIST" UUID="u">{prims}'
        '</PLAYLIST></NODE></SUBNODES></NODE></PLAYLISTS></NML>'
    )
    p = tmp_path / "collection.nml"
    p.write_text(xml, encoding="utf-8")
    return p


def _raw(name: str) -> str:
    # mismo cálculo que la vista previa: str(_location_to_path(...))
    from traktor_db import _location_to_path
    return str(_location_to_path("Z:", "/:nope/:", f"{name}.mp3"))


class TestTraktorFindBrokenScoped:
    def test_only_scoped_entries_are_returned(self, tmp_path: Path) -> None:
        root = ET.parse(_nml(tmp_path, ["a", "b", "c"])).getroot()
        sc = rc.RelocateScope("P", frozenset({_raw("a"), _raw("c")}))
        broken = tr.find_broken_entries(root.find("COLLECTION"), scope=sc)
        assert sorted(b.title for _, b in broken) == ["a", "c"]

    def test_no_scope_returns_all_like_before(self, tmp_path: Path) -> None:
        root = ET.parse(_nml(tmp_path, ["a", "b", "c"])).getroot()
        assert len(tr.find_broken_entries(root.find("COLLECTION"))) == 3

    def test_empty_scope_returns_nothing(self, tmp_path: Path) -> None:
        root = ET.parse(_nml(tmp_path, ["a", "b"])).getroot()
        sc = rc.RelocateScope("vacía", frozenset())
        assert tr.find_broken_entries(root.find("COLLECTION"), scope=sc) == []

    def test_out_of_scope_entries_never_hit_the_disk(self, tmp_path: Path, monkeypatch) -> None:
        root = ET.parse(_nml(tmp_path, ["a", "b", "c"])).getroot()
        seen: list[str] = []
        real = tr._location_to_path
        monkeypatch.setattr(tr, "_location_to_path", lambda v, d, f: (seen.append(f), real(v, d, f))[1])
        orig_exists = Path.exists
        checked: list[str] = []
        monkeypatch.setattr(Path, "exists", lambda self: (checked.append(self.name), orig_exists(self))[1])
        sc = rc.RelocateScope("P", frozenset({_raw("a")}))
        tr.find_broken_entries(root.find("COLLECTION"), scope=sc)
        assert checked == ["a.mp3"]

def _run_traktor(nml: Path, search: Path, scope, monkeypatch) -> tuple[list, list[str]]:
    monkeypatch.setattr(tr, "is_traktor_running", lambda: False)
    w = tr.RelocateWorker(nml, search, auto_resolve=True, scope=scope)
    logs: list[str] = []
    done: list[tuple] = []

    w.finished_ok.connect(lambda *a: done.append(a))

## Riesgos y caveats a declarar

1. **Nunca se probó contra la librería real ni contra Rekordbox/Traktor abiertos:** tests sobre NML sintético y DB falsa; el camino real de `update_content_path` + ANLZ no se ejercita (ya lo cubre ADR-002 / uso previo del global).
2. **Identidad por `raw_path` string exacto (T1):** si la vista previa y el motor calcularan la ruta distinto (p. ej. un cambio futuro de normalización), una pista rota quedaría fuera del alcance en silencio (sub-reparación, nunca sobre-reparación). Los tests fijan la igualdad en Traktor con `_location_to_path`.
3. **Pista repetida en varias playlists:** se repara para todas (es una sola entrada); el diálogo lo dice con una línea fija, sin enumerar las otras playlists.
4. **Corridas con alcance ignoran el tilde del menú (T5):** «Reparar enlaces de esta carpeta» siempre pregunta por ambigüedades.
5. **Windows vs macOS:** el comparador de rutas es string exacto; en Windows `Path` normaliza separadores y mayúsculas de unidad igual en vista previa y motor porque ambos usan el mismo helper. No probado en Windows (sin equipo).
