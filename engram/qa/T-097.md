## Defectos
1. **D1 (riesgo, medio)** `release.yml`: el trigger `pull_request` (mismo repo, no fork) SÍ recibe los secrets, así que ese run firma con Developer ID y notariza, y un PR que edite `scripts/release_mac.sh` o el workflow (ambos en `paths`) ejecuta código nuevo con el .p12 y la API key. El comentario de cabecera y `docs/RELEASE.md` dicen «PR => build ad-hoc de humo», lo cual es falso para PRs del mismo repo. Fix: condicionar los pasos de importar certificado y notarytool a `github.event_name != 'pull_request'` (o calcular SIGNING/NOTARIZING con esa condición) y corregir la doc.
2. **D2 (confiabilidad, medio)** `upload-artifact` sube `dist/*-src.tar.gz` y su `.sha256` desde las DOS patas con el mismo nombre; `download-artifact merge-multiple` los pisa entre sí (descarga en paralelo, gana el último por archivo). Si el gzip/tar difiere byte a byte entre runners, el `.sha256` publicado puede no corresponder al tarball publicado. Fix: subir el src solo desde una pata (p. ej. paso condicionado a `matrix.arch == 'arm64'`).
3. **D3 (correctitud, bajo)** paso «Resumen»: `${DEVELOPER_ID:+Developer ID}${DEVELOPER_ID:-ad-hoc}` imprime «Developer IDDeveloper ID Application: …» (el `:-` expande el valor cuando está seteado); idem `${NOTARY_PROFILE:+sí}${NOTARY_PROFILE:-no}` => «sílistbuddy». Reproducido en shell. Fix: `${DEVELOPER_ID:+Developer ID}${DEVELOPER_ID:-ad-hoc}` -> `$([ -n "${DEVELOPER_ID:-}" ] && echo Developer ID || echo ad-hoc)` o `if`.
4. **D4 (tests, P-18.4)** `tests/test_release_scripts.py::test_release_script_ci_hooks`: aserciones sobre texto fuente; mutación comprobada: renombrar el `case` de `--arch-suffix)` deja el test verde porque la cadena sigue en el mensaje de uso. No prueba el comportamiento (sufijo en el nombre del DMG). Fix: test que corra `release_mac.sh --dry-run --arch-suffix` (con `ALLOW_OLD_PYTHON=1`) y verifique que la salida contiene `ListBuddy-<v>-<uname -m>.dmg` y `.sha256`; opcionalmente un test estático de que release.yml invoca `scripts/release_mac.sh`.
5. **D5 (doc, bajo)** `docs/RELEASE.md` paso 3 de publicar: «2 de las 75 diarias por cuenta» no tiene fuente en el plan ni doc primaria de Apple. Citar fuente o quitar la cifra.
